## 2025-05-22 - Sequential Assignment UX

**Learning:** Batch assignments in FlexiRule are sequential state mutations where the order of execution significantly impacts the final result (e.g., set value then increment). Users need clear visual affordances to control this sequence.

**Action:** Always provide "Move Up/Down" reordering controls in list-based assignment builders. Use ghost buttons for these secondary actions to maintain focus on the configuration data while ensuring discoverability. Add a "Clear All" action in the header for complex builders to reduce the friction of manual deletion.
