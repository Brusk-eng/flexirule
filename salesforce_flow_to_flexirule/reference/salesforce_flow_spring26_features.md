# Salesforce Flow Spring '26 Features

## 1. Component-Level Styling Overrides

- **Description**: Native design flexibility for Screen Flows without custom components
- **Features**:
    - Customize background, text, and label colors
    - Control borders, spacing, and corner radius
    - Style containers, headers, and footers
- **Benefits**: Corporate branding alignment, improved readability, reduced development dependency

## 2. Kanban Board Component (Beta)

- **Description**: Visual display of records as cards grouped by picklist fields
- **Capabilities**:
    - Display records as cards
    - Group by Status, Stage, Priority, etc.
    - Show key record fields on cards
    - View summary values per column
- **Use Cases**: Opportunity pipelines, case lifecycle monitoring, queue management

## 3. New Message Component

- **Description**: Standardized messaging for clear, accessible communication
- **Types**: Information, Success, Warning, Error
- **Benefits**: Consistent UX, improved accessibility, better user guidance

## 4. Inline Editing and Sorting in Flow Data Tables

- **Features**:
    - Inline editing for text fields
    - Column-level sorting
    - Better usability for large datasets
- **Benefits**: Simplified data-heavy automation, reduced custom development

## 5. Persistent Debug Inputs

- **Description**: Saved debug input values for faster iteration
- **Features**:
    - Values stored in browser cache
    - Automatic repopulation during debugging
    - Persists across flow edits
- **Benefits**: Faster testing cycles, improved productivity

## 6. Collapsible Elements

- **Supported Elements**: Decisions, Loops, Wait paths, Async actions, Experiment branches
- **Benefits**: Reduced visual clutter, improved readability, easier maintenance

## 7. Enhanced Canvas Navigation

- **Improvements**: Mouse wheel scrolling, trackpad gestures, arrow key navigation
- **Benefits**: Better navigation of large flows, improved productivity

## 8. Content Object Triggers

- **Description**: Record-triggered flows on ContentDocument and ContentVersion
- **Use Cases**: File tagging, approval workflows, compliance checks, notifications
- **Benefits**: End-to-end file automation without Apex

## 9. Centralized Flow Logging and Metrics

- **Features**: Integration with Data Cloud for performance monitoring
- **Metrics**: Execution duration, success/failure rates, error details
- **Benefits**: Proactive governance, easier troubleshooting, enterprise scalability

## 10. AI-Powered Agentforce Setup Assistant (Beta)

- **Capabilities**: Natural language flow creation, troubleshooting assistance
- **Features**: Create flows via prompts, fix formulas, recommend solutions
- **Benefits**: Lower learning curve, empowered admins, faster development
