# Salesforce Flow Overview

Salesforce Flow is a powerful automation tool that allows users to build complex business processes without writing code. It provides a visual interface for creating workflows, data manipulations, and user interactions.

## Key Features

### Flow Types

- **Screen Flows**: Interactive flows with user screens for data collection and display
- **Record-Triggered Flows**: Automatically triggered when records are created, updated, or deleted
- **Autolaunched Flows**: Background processes triggered by other systems or processes
- **Schedule-Triggered Flows**: Run on a recurring schedule
- **Platform Event-Triggered Flows**: Triggered by platform events

### Building Blocks

#### Elements

- **Interaction Elements**: Screen, Action, Subflow
- **Logic Elements**: Decisions, Assignments, Transforms, Filters, Sorts, Loops
- **Data Elements**: Create, Update, Get, Delete records

#### Resources

- **Variables**: Store data (Text, Number, Record, Date, etc.)
- **Collections**: Groups of variables for bulk processing
- **Constants**: Fixed values
- **Formulae**: Dynamic calculations
- **Choices**: Options for user selections
