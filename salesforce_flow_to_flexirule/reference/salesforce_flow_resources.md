# Salesforce Flow Resources

## Variables

Variables are containers that store data for use throughout the flow.

### Types

- **Text**: String values up to 255 characters
- **Number**: Integer or decimal values
- **Currency**: Monetary values with currency formatting
- **Date**: Date values without time
- **DateTime**: Date and time values
- **Boolean**: True/false values
- **Picklist**: Selection from predefined options
- **Record**: Reference to a Salesforce record
- **Apex-Defined**: Custom types defined in Apex

### Properties

- **Input/Output**: Controls data flow direction
- **Default Value**: Initial value for the variable
- **Description**: Documentation for the variable's purpose

## Collections

Collections are groups of variables that can be processed together.

### Types

- **Record Collections**: Lists of Salesforce records
- **Primitive Collections**: Lists of simple data types (Text, Number, etc.)

### Operations

- **Add**: Append items to the collection
- **Remove**: Delete items from the collection
- **Clear**: Empty the entire collection
- **Loop Processing**: Iterate through each item

## Constants

Constants are fixed values that don't change during flow execution.

### Use Cases

- Configuration values
- Business rules thresholds
- API endpoints
- System identifiers

### Benefits

- Centralized management of fixed values
- Easy maintenance when values need to change
- Improved flow readability

## Formulae

Formulae are dynamic calculations that produce values based on other data.

### Functions

- **Mathematical**: ADD, SUBTRACT, MULTIPLY, DIVIDE
- **Text**: CONCATENATE, LEFT, RIGHT, MID
- **Date**: TODAY, NOW, DATEADD, DATEDIF
- **Logical**: IF, AND, OR, NOT
- **Advanced**: CASE, ISBLANK, ISNULL

### Syntax

- Uses Salesforce formula syntax
- Supports nested functions
- Can reference variables and constants

## Choices

Choices provide options for user selections in Screen elements.

### Types

- **Picklist Choice**: Static options defined in the flow
- **Record Choice**: Dynamic options from Salesforce records
- **Dynamic Choice**: Options generated by formulas or queries

### Display Options

- **Radio Buttons**: Single selection
- **Checkboxes**: Multiple selection
- **Picklist**: Dropdown selection
- **Visual Picker**: Icon-based selection

## Advanced Resources

### Apex-Defined Variables

- Custom data types created in Apex
- Enable complex data structures
- Support for objects and collections

### Global Constants

- System-wide constants available across all flows
- Maintained by administrators
- Include organization-specific values

### Flow Variables

- Special variables for flow metadata
- Include flow name, version, and execution context
- Useful for logging and debugging
